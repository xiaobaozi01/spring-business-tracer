# V2.0 Code Graph 契约回放（兼容旧回归夹具）

契约回放用于在没有真实 Code Graph MCP 的测试环境中验证 Agent 工作流。

## 启用条件

必须同时满足：

- 用户明确说明“契约回放测试”或等价表达；
- 提供固定的 Code Graph 响应文件；
- 响应包含工具能力、查询参数、结果和源码位置。

## 规则

1. 把响应文件当作已经发生的 Code Graph 调用记录，不把它当作普通源码推断。
2. 只能使用响应中存在的符号和调用边。
3. 可以读取响应指向的精确源码、XML和SQL进行验证。
4. 响应缺少的调用边必须标记为未确认。
5. 输出状态固定为 `TEST_ONLY`。
6. 在“Code Graph查询记录”中标明 `contract-replay` 和响应文件路径。
7. 不写入正式项目文档目录；写入测试任务指定的输出目录。
8. 全项目回放必须固定 config/source/index 指纹、入口清单、批次和预期边界；不得根据 `expected` 字段反推缺失调用边。
9. caller/impact、跨服务和恢复测试只能使用响应中明确存在的反向边、两侧边界证据和 checkpoint。
10. Subagent 验证必须独立读取固定查询记录，不把 worker 报告本身当事实源。
